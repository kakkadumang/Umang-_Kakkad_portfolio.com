How to Install on Android Phone:

1

Upar diye gaye "Install App on Phone / PC" button par click karein.

2

Agar prompt na aaye to Chrome browser ke top-right me 3 dots (⋮) dabayein aur "Install app" ya "Add to Home screen" chunein.

3

Phone ki home screen par official app icon set ho jayega. 1 click karte hi direct app open hogi!

How to Install on iPhone / iPad (Safari):

1

Safari browser mein neeche screen par Share button ⎋ Share par tap karein.

2

Share menu ko scroll karke "Add to Home Screen" (⊕) select karein.

3

Top-right corner par "Add" dabayein. Bas! Aapke iPhone screen par official UK logo ke saath app ready ho jayegi!

How to Install on Laptop / Desktop (Windows & Mac):

1

Upar diye gaye "Install App on Phone / PC" button par click karein.

2

Google Chrome ya Microsoft Edge ke Address Bar ke right side mein Install Icon [⊕] par click karein.

3

Desktop shortcut aur Windows Taskbar par app icon pin ho jayega — double click karte hi native standalone window open hogi!
